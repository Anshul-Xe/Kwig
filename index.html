Google Console Prerequisites:

  1. Go to Google Cloud Console, create a project, and search/enable Google Drive API.
  2. In OAuth Consent Screen:
    • Set User Type to External / state to Testing.
    • Add your email under Test Users (Required).
  3. Create OAuth Client ID (Web Application type):
    • Add Authorized Javascript Origin: https://localhost and http://localhost:5173
    • Add Authorized Redirect URI: https://localhost and http://localhost:5173
